01

Reject app names that escape the data directory

F8

~/.phelix/apps/<appName> is built from a name the user typed, and validateName only rejects the empty string. A name containing / or .. points at another app's directory, or outside ~/.phelix entirely. The same constructors are reached by names supplied over gRPC (rollback, matrix, health commands), so the check has to live where the path is built, not only at the flag parser.

The fix is one regular expression at that choke point. appDataDir and statePath already return an error, so no signature changes and no caller changes.

internal/deploy/version.go · above appDataDir 
// appNameRe keeps an app name to a single safe path component. The name
// becomes ~/.phelix/apps/<name>/, so separators, ".." and absolute paths
// must never reach the filesystem. A leading dot is rejected, which rules out
// both "." and "..".
var appNameRe = regexp.MustCompile(`^[A-Za-z0-9_-][A-Za-z0-9._-]{0,63}$`)

// ValidateAppName reports whether name can be used as an app's on-disk
// directory component. appDataDir and statePath enforce it themselves, so
// names arriving over gRPC are covered too; CLI callers check it early to
// fail before any state is written.
func ValidateAppName(name string) error {
	if !appNameRe.MatchString(name) {
		return phelixerr.Newf(phelixerr.CodeInvalidArgument,
			"invalid application name %q: use letters, digits, dot, dash or underscore (1-64 characters, no path separators)",
			name)
	}
	return nil
}

package deploy

import (
	"strings"
	"testing"

	phelixerr "github.com/abdorrahmani/phelix/internal/errors"
)

// An app name becomes a directory component; a name carrying a separator or
// ".." must never be turned into a path.
func TestValidateAppName(t *testing.T) {
	valid := []string{"api", "my-app", "my_app", "app.v2", "a", "9lives"}
	for _, name := range valid {
		if err := ValidateAppName(name); err != nil {
			t.Errorf("ValidateAppName(%q) = %v, want nil", name, err)
		}
	}

	invalid := []string{
		"",                       // empty
		"..",                     // parent directory
		".",                      // current directory
		".hidden",                // leading dot cannot become the app dir
		"../foo",                 // escapes the data directory
		"a/b",                    // nested path
		`a\b`,                    // windows separator
		"/abs",                   // absolute path
		"my app",                 // space
		strings.Repeat("a", 65),  // over the 64-character bound
	}
	for _, name := range invalid {
		err := ValidateAppName(name)
		if err == nil {
			t.Errorf("ValidateAppName(%q) = nil, want error", name)
			continue
		}
		if !phelixerr.IsCode(err, phelixerr.CodeInvalidArgument) {
			t.Errorf("ValidateAppName(%q) code = %s, want INVALID_ARGUMENT", name, phelixerr.CodeOf(err))
		}
	}
}

// The constructors must refuse on their own: callers that never run the CLI
// validator (gRPC paths) reach these directly.
func TestAppDataDirRefusesUnsafeName(t *testing.T) {
	t.Setenv("HOME", t.TempDir())
	if _, err := appDataDir("../escape"); err == nil {
		t.Fatal("appDataDir accepted a name that escapes the data directory")
	}
	if _, err := statePath("a/b"); err == nil {
		t.Fatal("statePath accepted a name with a path separator")
	}
}
Migration risk — check before you commit

Any app already on disk whose name breaks this rule (a space, a slash, a leading dot) loses its history operations: rollback fails with INVALID_ARGUMENT, and status/list quietly drop their version and deploy columns because those readers ignore deploy.Load errors. Run ./phelix list and confirm every name matches [A-Za-z0-9._-]. If one does not, rename it before merging: stop it, remove the entry, rebuild under a valid name. This is a deliberate fail-closed choice — a name that reaches the filesystem unchecked is worse than a name that is refused.

02

Delete the app data directory on remove --purge

F15 · F16

RemoveApplication deletes the binary, the log file and the apps.json entry. It never touches ~/.phelix/apps/<Name>/, which holds versions.json, builds/vN/ and the encrypted env/vN.enc snapshots. Those stay on disk forever, and the dashboard is told the app is gone.

Deleting them also closes F16 — "a reused name inherits the old app's version history" — because there is no history left to inherit. A second effect is worth knowing: health.json lives in the same directory, so it goes with it.

This is irreversible local data deletion, so it stays behind an explicit flag. The flag is the confirmation: no prompt, no silent default, and nothing changes for anyone who runs phelix remove app as before.

Bound compiler invocations

F6

Both builders run cmd.CombinedOutput() with no context and no deadline. A compiler waiting on a network fetch, a stuck cgo toolchain or a dead NFS mount hangs phelix build forever, with no diagnostic and no way out except a signal. Meanwhile BUILD_TIMEOUT is declared and mapped to exit 20 with nothing in the tree producing it.

One deadline, one shared helper, both builders. The CLI exposes it as --build-timeout, defaulting to 30 minutes.

// DefaultBuildTimeout bounds one compiler invocation when the caller sets no
// deadline. Without it a hung compiler blocks the CLI forever.
const DefaultBuildTimeout = 30 * time.Minute

// buildTimeout returns the effective deadline for one invocation.
func buildTimeout(d time.Duration) time.Duration {
	if d <= 0 {
		return DefaultBuildTimeout
	}
	return d
}

04

Fail the build when a code has no producer

F23

Commit 3 gave BUILD_TIMEOUT a producer, so nothing is orphaned today. The finding's second half is the guard: a test that fails when a constant is declared and never referenced outside its own definition. That turns "remember to check" into a build failure.

Two files are exempt by meaning: codes.go defines the constants, and cmd/cli_errors.go maps them to exit codes. A mapping is not a producer. CodeOK and CodeUnauthorized are allowlisted with a written reason — both are contract values that intentionally have no producer.

  • internal/errors/producers_test.go
internal/errors/producers_test.go · new 
package phelixerr

import (
	"go/ast"
	"go/parser"
	"go/token"
	"io/fs"
	"path/filepath"
	"sort"
	"strings"
	"testing"
)

// TestEveryCodeHasAProducer keeps the script-facing error contract honest: a
// declared code nothing in the tree can produce promises a state a script can
// never observe. The declaration file and the exit-code mapping do not count.
func TestEveryCodeHasAProducer(t *testing.T) {
	root, err := filepath.Abs(filepath.Join("..", ".."))
	if err != nil {
		t.Fatal(err)
	}

	// Codes that legitimately have no producer, with the reason.
	allowed := map[string]string{
		"CodeOK":           "success sentinel; ExitCodeFor maps it, nothing errors with it",
		"CodeUnauthorized": "reserved for a backend 401; the CLI fails with UNAUTHENTICATED instead",
	}

	fset := token.NewFileSet()
	used := map[string]bool{}

	err = filepath.WalkDir(root, func(path string, d fs.DirEntry, walkErr error) error {
		if walkErr != nil {
			return walkErr
		}
		if d.IsDir() {
			switch d.Name() {
			case ".git", "vendor", "releases", "node_modules", ".claude":
				return filepath.SkipDir
			}
			return nil
		}
		if !strings.HasSuffix(path, ".go") || strings.HasSuffix(path, "_test.go") {
			return nil
		}
		rel, relErr := filepath.Rel(root, path)
		if relErr != nil {
			return relErr
		}
		rel = filepath.ToSlash(rel)
		if rel == "internal/errors/codes.go" || rel == "cmd/cli_errors.go" {
			return nil
		}
		f, parseErr := parser.ParseFile(fset, path, nil, 0)
		if parseErr != nil {
			return parseErr
		}
		ast.Inspect(f, func(n ast.Node) bool {
			if id, ok := n.(*ast.Ident); ok && strings.HasPrefix(id.Name, "Code") {
				used[id.Name] = true
			}
			return true
		})
		return nil
	})
	if err != nil {
		t.Fatalf("walk the tree: %v", err)
	}

	declared, err := declaredCodes(fset)
	if err != nil {
		t.Fatalf("parse codes.go: %v", err)
	}

	var orphans []string
	for name := range declared {
		if used[name] {
			continue
		}
		if _, ok := allowed[name]; ok {
			continue
		}
		orphans = append(orphans, name)
	}
	sort.Strings(orphans)
	if len(orphans) > 0 {
		t.Fatalf("error codes declared but never produced: %s\n"+
			"Give each one a producer, delete it, or list it in allowed with a reason.",
			strings.Join(orphans, ", "))
	}

	// A stale allowlist entry is how this test quietly stops guarding anything.
	for name := range allowed {
		if !declared[name] {
			t.Errorf("allowed entry %q no longer exists in codes.go; remove it", name)
		}
	}
}

// declaredCodes returns every Code-prefixed constant declared in codes.go.
func declaredCodes(fset *token.FileSet) (map[string]bool, error) {
	f, err := parser.ParseFile(fset, "codes.go", nil, 0)
	if err != nil {
		return nil, err
	}
	declared := map[string]bool{}
	for _, decl := range f.Decls {
		gd, ok := decl.(*ast.GenDecl)
		if !ok || gd.Tok != token.CONST {
			continue
		}
		for _, spec := range gd.Specs {
			vs, ok := spec.(*ast.ValueSpec)
			if !ok {
				continue
			}
			for _, name := range vs.Names {
				if strings.HasPrefix(name.Name, "Code") {
					declared[name.Name] = true
				}
			}
		}
	}
	return declared, nil
}

## What

Four residual defects from the build-flow review, one commit each.

| Commit | Fixes | Effect |
|---|---|---|
| 1 | F8 | An app name is validated where it becomes a path, so no name can escape or collide inside `~/.phelix/apps/`. |
| 2 | F15, F16 | `phelix remove --purge` deletes the app's data directory: version history, build artifacts, encrypted env snapshots. A reused name no longer inherits a dead app's history. |
| 3 | F6 | Compiler invocations are `exec.CommandContext` calls with a 30 minute default, overridable with `--build-timeout`; a deadline reports `BUILD_TIMEOUT` (exit 20). |
| 4 | F23 | A test fails when an error code is declared and never produced. |

## Why

- **F8** — `appDataDir` and `statePath` concatenated an unvalidated name into a path. A name containing `/` or `..` reached the filesystem, including from gRPC handlers that never run the CLI validator.
- **F15** — `RemoveApplication` deleted the binary, the log and the `apps.json` entry, and left `~/.phelix/apps/<Name>/` forever. `deploy.Remove` already did the right `os.RemoveAll` and had no callers.
- **F6** — `GoBuilder.Build` and `RustBuilder.Build` ran `CombinedOutput()` with no context. A hung compile blocked the CLI with no diagnostic, while `BUILD_TIMEOUT` sat in the codeset, mapped to exit 20, produced by nothing.
- **F23** — that orphaned constant exposed the gap: nothing made "declared but unreachable" a build failure.

## Behaviour changes

- `phelix remove` keeps its current behaviour by default. Deleting the data directory requires `--purge`, and it is irreversible.
- App names must match `[A-Za-z0-9_-][A-Za-z0-9._-]{0,63}`. **Anyone with an existing app whose name breaks this rule will need to rename it** — check `phelix list` before merging.
- `phelix build` and `phelix rebuild` gain `--build-timeout` (default `30m`). A timeout now exits 20 with `BUILD_TIMEOUT` instead of hanging.

## Invariants held

- Two-phase promotion is untouched: nothing is promoted before health passes.
- `--purge` runs only on explicit removal, never from `discardAppEntry`'s failed-build cleanup, so it cannot touch a directory a different app owns.
- The exit-code contract is preserved: existing codes keep their exits, and `BUILD_TIMEOUT` keeps 20.

## Testing

- `go test ./...` — only the two pre-existing `internal/health` Caddy fixture failures remain.
- New `TestValidateAppName`, `TestAppDataDirRefusesUnsafeName`.
- New `TestRustBuild_DeadlineIsBuildTimeout` (sleeping `cargo` shim, 50 ms deadline).
- New `TestEveryCodeHasAProducer`, plus a `BUILD_TIMEOUT` → exit 20 row in `TestExitCodeFor`.
- Manual: `remove --purge` on a throwaway `HOME`; `build --build-timeout 1ns` exits 20.

## Not in this PR

Matrix and Docker build paths are not bounded by `--build-timeout`, and a killed compiler's grandchildren can briefly outlive it. Both are noted in the guide.
